## Тема для сайта «Веченозелёный сервис»

### Описание
--------
Локальная копия сайта на WordPress. Проект содержит файлы ядра WordPress и тему/плагины для разработки и тестирования локально.

### Требования
----------
- PHP (рекомендуется PHP 7.4+)
- MySQL или MariaDB
- Веб-сервер (Apache или Nginx) — для локальной разработки удобно использовать XAMPP

### Запуск локально
---------------
1. Убедитесь, что файлы проекта находятся в директории веб-сервера.
2. Запустите Apache и MySQL (через интерфейс веб-сервера или командой в терминале).
3. Создайте базу данных для WordPress (через phpMyAdmin или в консоли MySQL).
4. Скопируйте `wp-config-sample.php` в `wp-config.php` и укажите параметры подключения к базе данных (DB_NAME, DB_USER, DB_PASSWORD, DB_HOST).
5. Откройте в браузере адрес сайта, например:

```
http://localhost/evergreen_
```

### Дополнительно
------------
- Для импорта содержимого и настроек используйте админ-панель WordPress (`/wp-admin`).
- Если нужны права записи для кеша/загрузок, убедитесь, что веб-сервер имеет доступ к соответствующим папкам (`wp-content/uploads`, `wp-content/cache` и т.д.).
